# Planning SDK 0.1.61

Adds `scenario.show_mesh_iterations(iteration=None, save_path=None)` to browse
the saved construction snapshots after `add_repeaters()`. The view opens on
the last iteration and includes a dropdown for all earlier states, including
the initial network. Backbone accesses, repeaters and equipment leaves use
different symbols and colors. Unconnected equipment remains visible. Selected
paths show ranks and link metrics; node selection highlights its full path
toward the backbone and reports per-hop costs. Browsing performs no RF calls.

The distributed mesh network notebook replaces its two individual study views
with this browser and renames the complete construction result to `construction`.
Existing detailed study and final planning views remain available. No planning
algorithm or service API change is required.
