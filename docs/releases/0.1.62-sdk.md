# Planning SDK 0.1.62

`scenario.show_mesh_network()` now uses the same symbols, ranks, link metrics
and complete upstream path highlighting as the construction iteration browser.
It reads the top-level solved network, not the last construction snapshot, and
has no iteration selector. Clicking Copel therefore highlights the whole path
through Torre to Guaira. Unconnected equipment remains visible.

The generic `show_network()` view and candidate inspection remain available for
their existing purposes. The distributed mesh notebook uses `show_mesh_network()`
for its last cell. No planning algorithm or service API change is required.
