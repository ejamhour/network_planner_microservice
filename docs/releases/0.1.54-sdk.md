# SDK 0.1.54 — Salvar reconfiguração no projeto

No Jupyter, a confirmação grava `reconfiguration.json` na pasta do projeto usando a API Contents autenticada da própria sessão do navegador. O painel mostra o caminho somente depois de a API confirmar a gravação. Erros de autenticação ou gravação aparecem no painel, sem mensagem de sucesso e sem download como substituição silenciosa. Durante a gravação, os controles de alteração ficam desabilitados.

O SDK identifica o caminho relativo à raiz do servidor Jupyter, inclusive quando o workspace está em uma subpasta. Tokens de acesso não são incluídos na visualização. O iframe da revisão usa a mesma origem para acessar a sessão autenticada do Jupyter; visualizações comuns mantêm seu sandbox anterior.

O HTML aberto fora do Jupyter mantém uma opção explicitamente identificada como download. Nesse caso, o texto informa que não houve gravação no projeto. No notebook, use **Confirmar e salvar reconfiguration.json no projeto**, seguido de `project.load_reconfiguration(project.path / "reconfiguration.json")`.

O arquivo que havia sido baixado pelo usuário em Downloads foi validado e copiado para o projeto existente, sem alterar suas três solicitações de reconfiguração.
