# Planning SDK 0.1.39 — Installed GE topology and cellular redundancy

- Notebook 2 contains only SDK calls and graph visualizations.
- The example replaces Barigui with a device profile containing GE and public
  cellular interfaces. Both remain active. The device is connected at rank 1.0.
- Torre's GE interface is disabled; other sites remain enabled.
- Extension recipes support `[topology] mode = "installed"`. Preparation inherits
  only source-solution parent links and removes edges incident to disabled
  interfaces. Existing interface identities/radio fields are validated.
- The service supports candidate construction with manual links only, including
  an empty set. No geometric GE candidates are regenerated in installed mode.
- Network views show disabled inventory sites in gray, preserving their context.

Run the current prepare_workspace.py with --refresh-notebooks and restart the
kernel. Notebook names are unchanged. The new extension_fixed_links.toml recipe
is downloaded without replacing the user's earlier extension.toml. Notebook 2
explicitly uses the new filename; prepare(overwrite=True) backs up its old
generated scenario/results. The source project remains intact.

The example does not plan the cellular operator's RF network. The cost and
availability of that access are input assumptions. Connectivity and rank quality
remain distinct.
