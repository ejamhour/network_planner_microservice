# Planning SDK 0.1.63

Adds optional `antenna_placements.toml` installation overrides keyed by radio
interface ID. Profile defaults remain unchanged for omitted entries and fields.
The extension supports antenna catalog selection, per-interface mount heights,
azimuth, downtilt, sector width and the existing shadow modifiers. Unknown
references and invalid entries fail validation before a planning request.

Overrides are resolved locally into the existing canonical scenario. No new
service endpoint or RF algorithm is required. Effective antenna definitions
are isolated per interface and survive scenario export and mesh snapshots.
Derived projects preserve and track the placement file. The AGU E06 project
includes an empty template without invented installation data.

Automatic antenna selection and equipment replacement remain future work.
