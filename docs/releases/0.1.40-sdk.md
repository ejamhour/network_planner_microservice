# SDK 0.1.40

## Modelos de referência da tecnologia

`BaselineProject` organiza o treinamento e a avaliação local de RSSI com
registros medidos e features já calculadas. O projeto usa `baseline.json`
para selecionar os dados, definir expressões e ajustar o modelo em etapas.
Os resultados são gravados no workspace, sem importar módulos do servidor.

Métodos públicos:

- `train()`: ajusta as etapas e salva o modelo JSON e o resumo do treinamento.
- `evaluate(rssi_threshold_dbm=...)`: compara previsão e medição, mantendo as
  contribuições e os quatro grupos de orientação de intervenção.
- `export_metric(required_rssi_dbm=..., db_per_cost=...)`: gera uma métrica TOML
  com a previsão do modelo e sua conversão em custo positivo.
- `show_training()` e `show_evaluation()`: exibem gráficos no notebook e salvam
  visualizações HTML locais. A avaliação permite selecionar os enlaces.

O cálculo de ajuste foi portado do núcleo RF para permitir treinamento local
sem dependência do pacote do servidor. O contrato JSON do modelo foi mantido.
O código RF existente do serviço não foi alterado nesta entrega.

O extra `baseline` instala NumPy para treinamento; `notebook` também o inclui.
Não foi acrescentado um importador de arquivos legados nem uma nova rotina de
extração geográfica: o exemplo utiliza os registros preparados manualmente.

## Demonstração E08

Projeto: `examples/projects/e08_baseline_copel`.
Notebook: `examples/notebooks/e08_baseline_tecnologia.ipynb`.
Dados: `examples/data/e08`.
Modelo e métrica: `examples/metrics/e08_copel_rssi.json` e `e08_copel.toml`.

O notebook contém somente chamadas ao SDK e foi executado no Python local.
Reproduziu os ajustes de 243, 188, 521 e 1.890 registros e o erro absoluto
médio de 8,6198685095 dB da execução original. As features foram reutilizadas,
sem requisições aos serviços. Os 15 testes de baseline e preparação passaram;
a métrica compilada foi comparada com a previsão para os 1.890 registros.

A wheel 0.1.40 está em `dist/`, servida pelas rotas existentes de distribuição
quando o microserviço estiver em execução. O contêiner estava desligado nesta
validação; os testes HTTP de distribuição não foram executados no ambiente
local por ausência do FastAPI.
