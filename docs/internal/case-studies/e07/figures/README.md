# Figuras do relatório E07

Capturas estáticas das visualizações HTML produzidas pelo SDK a partir dos resultados dos projetos distribuídos. Os dados e as cores são os apresentados pelas visualizações; não foram redesenhados para o relatório.

- `fig01_rede_original.png`: visão geral de `e07_ge_mesh_original/solution_network.html`, com rótulos habilitados.
- `fig02_inspecao_qualidade.png`: mesma visualização, com Copel selecionado e os atributos de qualidade visíveis no painel.
- `fig03_inspecao_dependencias.png`: visualização `e07_ge_mesh_original/dependencies.html`, com Barigui selecionado e sua sub-rede descendente destacada.
- `fig04_rede_com_redundancia.png`: visão geral de `e07_ge_mesh_redundancia/solution_network.html`, com rótulos habilitados.

Capturas feitas no Chrome em viewport de 1100 × 820 pixels, com escala de imagem 2. As figuras incorporadas ao Markdown e ao Word são estáticas; a interação permanece disponível nas visualizações abertas pelos notebooks. As legendas e os parágrafos explicativos estão no Markdown do relatório.
